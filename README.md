# FairShare

**CS6983 Project 2 — Group Expense Sharing**

FairShare is a proposed full-stack web application for group expense tracking, accurate bill splitting, debt simplification, and settlement/audit workflows. See the [product specification](docs/FAIRSHARE_PRODUCT_SPEC.md) for planned features and constraints. This repository currently contains planning and HW3 evidence; it is **not** presented as a finished P2 implementation.
